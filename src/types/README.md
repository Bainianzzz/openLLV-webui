# 类型契约

本模块描述 openLLV-server 的请求、响应和前端归一化视图类型。类型字段优先忠实反映网络契约，因此 API 字段保留 snake_case。

## 组织方式

- `index.ts`：分页、通用错误体、任务摘要和按 `kind` 区分的任务详情联合类型。
- `artifacts.ts`：Artifact 元数据、目录内容和图片上传请求。
- `enhancement.ts`：增强能力目录与提交请求。
- `training.ts`：训练能力目录、数据集选项和提交请求。
- `datasets.ts`：已管理数据集、列表参数、下载请求和归一化任务视图。
- `tasks.ts`：任务筛选参数，并重新导出公共任务类型。

## 约定

- 服务端契约变更以 [API 文档](../../docs/README.md) 为准，并与对应 `src/api/` 模块一起更新。
- `TaskDetail` 通过 `kind` 形成可判别联合，使用前应先缩窄任务类型。
- 类型目录不放运行时转换逻辑；响应校验和归一化由 API 模块执行。
- 只有前端已经完成归一化的结构才命名为 `View`，避免把可选的网络字段伪装成必需字段。
- 新增共享结构前先检查已有领域类型，避免继续复制同一网络模型。
