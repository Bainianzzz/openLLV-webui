# 业务组合式函数

本模块承载页面与 API 之间的有状态业务编排，包括表单状态、并发请求、轮询、取消、可见性处理和组件卸载清理。状态按组合式函数实例隔离，不使用全局 Store。

## 模块

| 目录 | 职责 |
| --- | --- |
| `datasets/` | 加载数据集目录和列表、提交下载任务、刷新列表 |
| `training/` | 加载模型和数据集选项、校验表单、提交训练、解析 checkpoint |
| `tasks/` | 任务列表筛选分页、任务详情和取消 |

## 约定

- 通过 `@/api` 下的端点模块访问服务端，不在组合式函数中直接使用 Axios。
- 对可替换或长时间运行的请求使用 `AbortController`，在新请求和 `onUnmounted` 时清理。
- 定时器必须在终态、页面卸载或对应暂停条件出现时释放。
- 对依赖页面可见性的轮询监听 `visibilitychange`，恢复时只继续非终态的活动任务。
- 返回 Vue 的 `ref`、`reactive` 和 `computed` 状态以及明确的页面动作，不引入类式状态容器。
- 向页面暴露可展示的错误状态。

## 测试

测试与实现共置并命名为 `*.test.ts`。涉及生命周期钩子时，使用宿主组件挂载组合式函数；涉及轮询时使用 Vitest fake timers，并验证定时器和请求都能正确清理。
